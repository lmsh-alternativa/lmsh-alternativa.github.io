# ЛМШ «Альтернатива»

Сайт областного профильного лагеря «Летняя многопрофильная школа "Альтернатива"» при ЦДОД: учёба, неучебка, история смен с 2007 года, педсостав и запись на собеседования.

**Сайт:** https://lmsh-alternativa.github.io

## Как устроен

Обычный статический сайт на HTML, CSS и чуть-чуть JavaScript. Ни сборки, ни фреймворков, ни зависимостей нет. Чтобы посмотреть сайт у себя, открой `index.html` в браузере.

Сайт выкладывается через GitHub Pages: после пуша в `main` изменения появятся на сайте через минуту-две.

## Как редактировать

Подсказки лежат прямо в HTML, в комментариях `<!-- ... -->` рядом с нужным местом. Самое частое:

### Добавить смену в историю

В `history.html` скопируй блок `<article class="shift">` и вставь его над самой свежей сменой. Поменяй год в `id="smena-ГОД"` и в заголовке, впиши руководство и рассказ. Фото положи в `smeny/ГОД/`. Ссылка на год в навигации появится сама.

### Добавить человека

В `people.html` скопируй блок `<li>` и впиши имя, годы и кафедру. Годы пиши через запятую, подряд идущие можно диапазоном: `2016–2019, 2021`. Кафедру пиши так же, как у остальных: Физмат, Химбио, Гуманитарные науки, Информатика, Математика, Биология. Кнопки фильтров соберутся из этих подписей сами.

Фильтр можно открыть сразу по ссылке: `people.html?year=2024` или `people.html?dept=Физмат`.

### Фото

Если у человека или смены нет фото, строку `<img>` можно просто удалить, блок подстроится. Фото в блоках `<div class="photos">` открываются крупно по клику, сетка подстраивается под любое количество.

### После правки `style.css` или скриптов

Стили и скрипты подключаются с номером версии: `style.css?v=4`, `people.js?v=2`. После правки увеличь номер на всех страницах (поиск и замена `?v=4` → `?v=5`), иначе браузеры могут показать старую версию из кэша.
